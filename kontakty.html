РЕЕСТР ИНЖЕНЕРНОГО СОСТАВА // LOG-AI GROUP

Распределенная проектная команда из 10 профильных специалистов. Официальное оформление (ИП / Самозанятые), работа строго по договору и NDA с фиксацией ответственности.

ШТАТ: 9 УЗЛОВ
01

Главный архитектор систем // dev_01

Аудит производственных процессов заказчика, проектирование логики распределенных систем и сквозная оркестрация данных.

02

Ведущий инженер интеграций ERP

Проектирование коннекторов, integration систем 1С:ERP, МойСклад, Битрикс24 и построение мостов обмена данными.

03

Старший инженер данных (Pipeline)

Разработка транзакционных очередей, маршрутизация внутренних API и защита от потерь пакетов при нагрузках.

04

Системный архитектор DevOps

Обеспечение безопасности инфраструктуры, развертывание локальных систем в изолированных Docker-контурах.

05

Дежурный инженер (Мониторинг 24/7)

Круглосуточный непрерывный контроль стабильности серверов, проверка лимитов API и предотвращение сбоев.

06

Инженер реверс-инжиниринга [Урал]

Связывание закрытого софта, работа со старыми промышленными протоколами станков и создание API-переходников.

07

Разработчик мобильных терминалов

Создание корпоративных мобильных приложений для складского учета, ТСД и оперативной работы сотрудников.

08

Ведущий бэкенд-разработчик

Оптимизация тяжелых реляционных баз данных PostgreSQL, написание ядра серверной логики системы.

AI

Log-AI // Автономный ИИ-модуль

Локальные LLM-модели (Ollama), векторные базы знаний Qdrant. Круглосуточный лингвистический анализ ТЗ.
